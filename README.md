## US English

### What is KolayCss?
**KolayCss** is a minimalist and developer-friendly CSS framework paired with a smart JavaScript engine. Instead of struggling with bulky external stylesheet links, its lightweight JS core automatically detects your HTML structure and injects the required CSS rules directly as styles on the fly.

### Key Features
* **Zero-Configuration:** No need for complex build tools or cumbersome CSS link tags.
* **Dynamic Injection:** Automatically renders and applies only the styles your project needs.
* **Ultra Lightweight:** Built for speed and efficiency, keeping asset sizes to an absolute minimum.
* **Plug & Play:** Ready to integrate into any project within seconds.



## TR Türkçe

**KolayCss**, akıllı bir JavaScript motoruyla desteklenen, minimalist ve geliştirici dostu bir CSS framework'üdür. Hantal harici stil dosyalarıyla uğraşmak yerine, hafif JS çekirdeği HTML yapınızı otomatik olarak algılar ve anında doğrudan stil kurallarını enjekte eder.

### Temel Özellikler
* **Sıfır Yapılandırma:** Karmaşık derleme araçlarına veya hantal CSS bağlantı etiketlerine gerek yoktur.
* **Dinamik Enjeksiyon:** Yalnızca projenizin ihtiyaç duyduğu stilleri otomatik olarak oluşturur ve uygular.
* **Ultra Hafif:** Hız ve verimlilik için tasarlanmış olup dosya boyutlarını mutlak minimumda tutar.
* **Tak-Çalıştır:** Saniyeler içinde herhangi bir projeye entegre edilmeye hazırdır.
