## 🇬🇧 English

### What is KolayCss?
**KolayCss** is a minimalist and developer-friendly CSS framework paired with a smart JavaScript engine. Instead of struggling with bulky external stylesheet links, its lightweight JS core automatically detects your HTML structure and injects the required CSS rules directly as styles on the fly.

### Key Features
* **Zero-Configuration:** No need for complex build tools or cumbersome CSS link tags.
* **Dynamic Injection:** Automatically renders and applies only the styles your project needs.
* **Ultra Lightweight:** Built for speed and efficiency, keeping asset sizes to an absolute minimum.
* **Plug & Play:** Ready to integrate into any project within seconds.

### Installation & Usage

Include the `kolaycss.js` file in your HTML document (preferably in the `<head>` or just before the closing `<body>` tag):

```html
<script src="[https://cdn.jsdelivr.net/gh/your-username/kolaycss@main/kolaycss.min.js](https://cdn.jsdelivr.net/gh/your-username/kolaycss@main/kolaycss.min.js)"></script>
